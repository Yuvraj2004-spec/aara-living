# Showroom assets

Downloaded from Poly Haven public asset API. All assets CC0: https://polyhaven.com/license

- fabric_pattern_07: normal and roughness maps, 1K. https://polyhaven.com/a/fabric_pattern_07
- wood_floor_deck: diffuse, normal, roughness maps, 1K. https://polyhaven.com/a/wood_floor_deck
- poly_haven_studio: HDR environment, 1K. https://polyhaven.com/a/poly_haven_studio
- potted_plant_02: glTF, binary and 1K textures. https://polyhaven.com/a/potted_plant_02

Geometry for bedding, curtains and upholstered furniture is project-authored. No generated photograph is substituted for interactive geometry.

The runtime plant is plant/plant-optimized.glb (Meshopt + WebP), produced using glTF Transform. Original source glTF is retained for provenance and reproducibility. Original transfer 2.63 MB; optimized GLB 888.38 KB.
